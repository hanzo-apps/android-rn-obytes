# android-rn-obytes

Production React Native starter — auth flow, i18n, forms, TanStack Query, MMKV.

**Lane:** Expo / React Native · **Live demo:** https://android-rn-obytes.hanzo.app

## Run it on Android

```sh
pnpm install && pnpm android
```

## Provenance

Forked from [obytes/react-native-template-obytes](https://github.com/obytes/react-native-template-obytes) — `.`, licensed **MIT**.

its authors. Changes made here are limited to what a standalone fork needs

## Preview

`npx expo export -p web` produces the static bundle served at
https://android-rn-obytes.hanzo.app — the same app the Android build runs, rendered by
react-native-web. It is a real running app, not a screenshot.
